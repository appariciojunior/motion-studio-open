# Conceptual starter set

Eight square, crop-safe 1080×1080 JPEG assets for Motion Studio Open. The collection
combines two visual modes: tactile athletic photography and restrained
editorial objects/graphics.

Palette: carbon black, warm ivory, burnt amber, oxblood, and powder blue.

1. Runner in amber dust
2. Monochrome athlete portrait
3. Ceramic continuous-loop sculpture
4. Black kinetic mark on powder blue
5. Victory silhouette on oxblood gradient
6. Long-exposure runner in ochre fog
7. Midnight pace dial
8. Suspended amber technical fabric

The images contain no copy or branding so typography can be layered and
animated separately in the editor.
